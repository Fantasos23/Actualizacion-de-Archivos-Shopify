# Actualizacion-de-Archivos-Shopify
Con este repositorio poder conocer como estan estructurados nuestros productos en Shopify como cada Campo se alimenta para poder reemplazar dichos valores de manera masiva al ejecutar los diferentes archivos que tenemos.

Generar_esquema.py para tener creado el Archivo JSON con la informacion de Schema de productos, y luego ejecutar el archivo APP.py para poder ejecutar la actualizacion de manera masiva de los productos por medio de archivos de excel o bases de datos. todo esto realizado por medio de la API directa de Shopify.
